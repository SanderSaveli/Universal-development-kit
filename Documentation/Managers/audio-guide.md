# Настройка аудио

Аудиомодуль UDK использует `AudioManager` для воспроизведения эффектов и управления музыкой. 
* `SoundConfig` задаёт варианты и параметры одного эффекта. 
* `AudioCatalog` собирает эти конфиги в набор, по которому менеджер ищет эффекты. 

Страница [AudioManager](audio-manager.md) описывает публичный API и содержит полный пример компонента.

## Настройте эффект

1. В окне **Project** выберите **Create → UDK → Audio → SoundConfig**.
2. Введите ID с учётом регистра, например `UI/Click`.
3. В `Clips` добавьте хотя бы один элемент и назначьте в каждом элементе импортированный `AudioClip`.
4. Нажмите **Play** в инспекторе, чтобы прослушать случайно выбранный вариант в Edit Mode. Каждое нажатие заново выбирает вариант с учётом `Avoid Repetition`. **Stop** применяет `Fade Out`, если воспроизведение уже началось. Предпрослушивание прекращается при смене выделения. Cooldown применяется при вызове по ID в игре.

### Параметры SoundConfig

| Поле | Назначение |
| --- | --- |
| `Id` | Ключ эффекта. Разделитель `/` образует группы в сгенерированном классе, например `UI/Click` даёт `Sounds.UI.Click`. |
| `Clips` | Список вариантов. При запуске выбирается один случайный элемент. |
| `Clip` | Аудиофайл варианта в `Clips`. |
| `Gain Db` | Поправка уровня отдельного варианта от `−20` до `+12` дБ. По умолчанию `0` дБ. Удобна для выравнивания уровня разных клипов. |
| `Avoid Repetition` | При нескольких вариантах исключает предыдущий индекс. Если один аудиофайл добавлен в разные элементы списка, он всё равно может прозвучать подряд. |
| `Loop` | Повторяет клип до остановки эффекта. |
| `Min Cooldown` | Минимальный интервал в секундах между запусками одного ID через конкретный менеджер. |
| `Fade In` | Длительность нарастания громкости в секундах. |
| `Fade Out` | Длительность затухания в секундах. Применяется при естественном завершении незакольцованного эффекта и при вызове `AudioHandle.Stop()`. |
| `Volume Range` | Случайная линейная громкость от `0` до `1`. При `1–1` случайного изменения нет. |
| `Pitch Range` | Случайный множитель высоты и скорости воспроизведения от `0.01` до `2`. При `1–1` используется исходная высота. |

Громкость из `Volume Range` сочетается с `Gain Db` выбранного клипа и громкостью группы эффектов. Если сумма фейдов длиннее незакольцованного клипа при выбранном pitch, оба фейда пропорционально сокращаются.

## Соберите каталог и сгенерируйте ID

1. Выберите **Create → UDK → Audio → Sound Catalog**. Созданный ассет имеет тип `AudioCatalog`.
2. Заполните список `Sounds` ссылками на `SoundConfig`. Для каждого ID в одном каталоге нужна одна запись.
3. Откройте любой `SoundConfig`, нажмите **Generate IDs** и дождитесь компиляции. Генератор собирает уникальные ID из всех `SoundConfig` проекта и записывает `Assets/Generated/Audio/Sounds.Generated.cs`. В проекте игры храните этот файл и его `.meta` вместе с аудиоконфигами.
4. Откройте каталог и нажмите **Validate Catalog**. Инспектор сверит его записи со сгенерированным набором ключей. Перед сборкой игры проверяется актуальность файла ключей. В Play Mode при назначении каталога менеджер отдельно проверяет ссылки, ID и варианты клипов.

Для смены оформления создайте второй каталог с теми же ID. Например, конфиги `UI/Click` в двух каталогах могут ссылаться на разные клипы. Вызов `SetCatalog` переключит набор для последующих запусков. Если переименовать ID, сгенерируйте ключи снова и обновите обращения к прежнему ID, включая сохранённые строковые значения.

Если генерация сообщает об ошибке, проверьте пустые ID, допустимость сегментов пути как имён C# и конфликты имён. Например, `UI/Click` и `UI/Click/Soft` одновременно требуют, чтобы `Click` был и полем, и группой.

## Подключите менеджер в сцене

1. Добавьте `AudioManager` в контейнер DI и назначьте каталог в **Default Catalog**.
2. В **Audio Mixer** назначьте [MasterAudioMixer.mixer](../../Runtime/Scripts/Managers/AudioManager/MasterAudioMixer.mixer) из пакета. Он содержит группы `Master/Music` и `Master/Sounds/SFX Gain`, а также параметры `MusicVolume` и `SoundsVolume`. 
3. Добавьте `AudioSource` для музыки и назначьте его в **Music Audio Source**. Для запуска из кода выключите **Play On Awake**. Менеджер назначит источнику группу `Master/Music` при инициализации. Проверьте, что в сцене есть активный `AudioListener`.
4. После инициализации установите `IsSoundOn = true` и, если нужна музыка, `IsMusicOn = true`. Оба канала изначально заглушены. Для музыки задайте параметры источника, вызовите `ChangeMusic(clip)`, затем `Play()` у назначенного `AudioSource`.
5. Вызовите `PlaySound(Sounds.UI.Click)` с импортом `SanderSaveli.UDK.Audio` или `PlaySound("UI/Click")`. Для запуска клипа напрямую используйте перегрузку с `AudioClip`.

## Управляйте воспроизведением

`PlaySound` возвращает `AudioHandle`. `IsPlaying` означает, что эффект занимает слот пула, в том числе во время загрузки или затухания. `IsCompleted` становится истинным после освобождения слота и сразу истинно у дескриптора по умолчанию. Если звук зациклен, сохраните дескриптор и вызовите `Stop()` для остановки с фейдом или `StopImmediate()` для немедленной остановки.

Если эффект не слышно в Play Mode, проверьте `IsSoundOn`, `SoundVolume`, `AudioListener`, назначенный каталог и клип. Если дескриптор сразу завершён, проверьте также ID, cooldown и свободные слоты. Число одновременно активных эффектов ограничено полем **Max Simultaneous Sounds**.
